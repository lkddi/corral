# ADR-005: TLS 采用随包 mkcert + MVP 通配符证书

## Status: Accepted (2026-10-26)

## Background
一键 HTTPS 且免浏览器警告是硬需求；mkcert 是 Valet/Herd/Laragon/Lerd 共同验证的方案。

## Decision
随包分发 mkcert；首次授权流程内完成 CA 信任（mac keychain / win LocalMachine\Root）；MVP 签发单张通配符证书复用，per-site 证书留 v1.0。

## Consequences
- 正面：实现最简、证书管理成本近零。
- 负面：Windows 装 CA 需管理员；通配符方案在 v1.0 做 per-site 时需迁移设计；Firefox 需 NSS 单独处理（文档化）。
