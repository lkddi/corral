# ADR-002: 核心引擎与 Electron 解耦，daemon 独立进程常驻

## Status: Accepted (2026-10-26)

## Background
服务必须在关窗后存活；CLI 需要在 GUI 未开时可用；未来若体积成为采用障碍，需能只换壳。

## Decision
core 包零 Electron import，作为独立 daemon（单实例：锁文件 + 端口探测）运行。GUI 壳（Electron main）/ CLI / daemon 三方解耦：后两者均为 daemon 客户端，彼此不直连；CLI/GUI 命令同源注册表（shared/commands.ts：RPC 与 CLI 命令 1:1 + 命令字符串模板）。预留未来将 daemon 包装为 Tauri sidecar 的迁移路径（只重写壳，核心不动）。

## Consequences
- 正面：关窗不停服、CLI 独立可用、壳可替换；CLI 冷启动走纯 Node 路径，满足 <300ms 红线；GUI 每个操作可展示并复制等价 `corral` 命令（差异化点）；开机启动由 daemon 自装登录项，不依赖壳插件。
- 负面：多一个进程与单实例协调复杂度。
- 版本连带：CLI / daemon / Windows helper 随包的独立 Node 运行时统一钉 **24.22.0**，与 Electron 45 捆绑 Node 逐位对齐（排障时全系统只有一个 Node 变量）。
