# ADR-003: 本地 DNS 双端策略（macOS dnsmasq + resolver / Windows hosts + helper 服务）

## Status: Accepted (2026-10-26)

## Background
.test 解析是产品核心；macOS 有 /etc/resolver 机制可通配，Windows 没有等价机制。

## Decision
macOS：写 /etc/resolver/test + dnsmasq（root launchd daemon，-u 降权）。Windows：由 SYSTEM helper 服务（安装时经 NSSM + ELECTRON_RUN_AS_NODE=1 注册）维护 hosts 精确条目；helper 只做写 hosts 与装证书两件事，命令白名单制。

## Consequences
- 正面：两端均达成「零配置访问站点」。
- 负面：Windows 无通配符（PRD/Spec 必须写明）；hosts 可能被安全软件干扰（重试 + 检测）；需一次性提权。
