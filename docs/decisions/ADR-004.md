# ADR-004: PHP 运行时按需下载预编译二进制（macOS 静态构建 / Windows 官方 zip）

## Status: Accepted (2026-10-26)

## Background
PHP 7.4-8.5 全量随包会使安装包膨胀数倍；Herd 已验证按需下载模式。

## Decision
app 内 catalog + SHA256 校验 + 解压到应用数据目录；macOS 用 static-php-cli 静态构建（CI 自建或官方预编译），Windows 用官方 NTS zip + php-cgi（每版本独占 FastCGI 端口）。MVP 先上 8.1/8.2/8.3/8.4 四个主力版本，7.4/8.0/8.5 第二批。

## Consequences
- 正面：安装包小、版本可增删、分发管线先求稳。
- 负面：静态构建扩展集固定不可 pecl（Spec 限制声明）；Windows 端进程模型与 mac 不同（php-cgi 进程池自写）。

## Related ADRs
- ADR-001（随 app 更新解耦的 catalog 通道）
- ADR-003（首次授权流程合并）
- ADR-008（MySQL/Redis 复用本 ADR 分发模式）
- ADR-009（修订「扩展集」为确定清单 + Xdebug 内置）

## Amendment (2026-10-26 · R13)
- **分发诠释确认**：按需下载（用户选择版本 → catalog 自动下载 + SHA256），不采取全内置。
- **「扩展集固定不可 pecl」的具体化**：固定集 = ADR-009 确定清单（Laravel 硬需求 + 开发默认 + 平台条件），不再是未定义约束；Xdebug 3.x 随版本内置、mode 默认 off。
- 连带：MySQL/Redis 复用同一 catalog 通道（ADR-008），catalog 实体从「仅 PHP」扩为「PHP + services」。

## Amendment (2026-10-28 · I1 实测修订)

I1 落地时发现两条与本决策相关的事实，均已在实现层修正：

1. **一个版本需要两份制品**：上游 `php-<v>-fpm-<platform>.tar.gz` 只含 `php-fpm`，不含 `php` CLI；另发 `php-<v>-cli-<platform>.tar.gz`。只装 fpm 会导致项目内 `artisan`/composer 不可用。现实现为双制品合并解包（约 28MB/版本）。
2. **构建变体分档**：`common`（默认，体积小，实测缺 `intl`/`xdebug`）与 `bulk`（扩展更全，体积更大，待 I2 用真实归档验证）。catalog 增 `phpBuild` 开关，缺口由 `corral doctor` 的 `php-ext-<v>` 检查显式暴露。

下载通道同时补上 Range 断点续传与长度校验（上游 CDN 会在数 MB 处重置连接）。详见 `docs/spikes/2026-10-28-php-runtime.md`。
