# ADR-004: PHP 运行时按需下载预编译二进制（macOS 静态构建 / Windows 官方 zip）

## Status: Accepted (2026-10-26)

## Background
PHP 7.4-8.5 全量随包会使安装包膨胀数倍；Herd 已验证按需下载模式。

## Decision
app 内 catalog + SHA256 校验 + 解压到应用数据目录；macOS 用 static-php-cli 静态构建（CI 自建或官方预编译），Windows 用官方 NTS zip + php-cgi（每版本独占 FastCGI 端口）。MVP 先上 8.1/8.2/8.3/8.4 四个主力版本，7.4/8.0/8.5 第二批。

## Consequences
- 正面：安装包小、版本可增删、分发管线先求稳。
- 负面：静态构建扩展集固定不可 pecl（Spec 限制声明）；Windows 端进程模型与 mac 不同（php-cgi 进程池自写）。
