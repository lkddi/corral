# ADR-009: PHP 扩展默认集（Laravel 就绪）+ Xdebug 内置与 debug 开关

## Status: Accepted (2026-10-26 · 用户需求变更 R13)

## Background
用户（2026-10-26）要求：① PHP 版本用户可选择、选择后自动下载（ADR-004 已锁定的按需下载模式，本 ADR 确认无变更）；② 默认支持 Laravel 所需扩展；③ 增加 debug 能力。原 ADR-004「静态构建扩展集固定」仅声明约束，未定义集合；Laravel 官方系统需求 + 本地开发常用扩展需一份确定清单，Xdebug 需明确分发与开关机制。

## Decision
1. **分发模式确认**：沿用 ADR-004 按需下载（catalog + SHA256），用户选择版本即自动下载安装，MVP 默认呈现 8.1/8.2/8.3/8.4，7.4/8.0/8.5 按需。
2. **默认扩展集**（每个 PHP 版本分发包内置，README 与 `corral php:list --json` 的 extensions 字段公布）：
   - Laravel 硬需求（官方系统需求）：`ctype` `curl` `dom` `fileinfo` `filter` `hash` `mbstring` `openssl` `pcre` `pdo` `session` `tokenizer` `xml`
   - 开发默认附带：`zip` `bcmath` `intl` `gd` `pdo_mysql` `pdo_pgsql` `sqlite3` `redis`（phpredis，与 ADR-008 Redis 服务闭环）`xdebug`
   - 平台条件：`pcntl` `posix` 仅 macOS（Windows php-cgi 无，README 注明）
   - 按需清单（v1.x 用户申请后评估）：`imagick` `soap` `exif` `ev` `swoole`
3. **Xdebug 内置**：每个 PHP 版本的 CI 构建产物内置 xdebug 3.x（与 PHP 小版本对齐），**不运行时 pecl 安装**（延续 ADR-004 静态集纪律）；安装即就绪，默认 mode=off。
4. **debug 开关**：`corral debug:on [site]` / `corral debug:off [site]`——写该作用域 php.ini 的 xdebug 段（mode=develop,debug；site 缺省 = 全局默认版本）；`discover_client_host` 自动探测本机局域网 IP；IDE 联动配置（VS Code / PhpStorm launch.json 模板）由 `corral doctor` 输出与 README 提供，不引入 IDE 插件。
5. **GUI**：debug 开关入 PHP 视图分段区旁（I4）； Services 视图同增量。

## Consequences
- 正面：`corral link` 后的 Laravel 项目零额外扩展安装；Xdebug 开箱即用且免费（Herd 侧为付费点之一）；扩展清单确定化后 doctor 可做完整性校验。
- 负面：静态构建产物体积增大（xdebug + redis 扩展约 +2MB/版本，可忽略）；gd/intl 等扩展的构建依赖进 CI 矩阵（libpng/icu 交叉编译，macOS 静态构建注意 licensing 无关但体积上升）；Windows 端 php.ini 扩展路径与目录隔离规则需与 mac 对齐测试。
- 约束延续：扩展集固定 → 用户要装清单外扩展 = 不支持（README 明示），这是「零依赖开箱」哲学的代价。
