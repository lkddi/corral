# ADR-006: Lucide 作为唯一 SVG 图标库

## Status: Accepted (2026-10-26)｜Amendment (2026-10-26 补登)

## Background
团队 P0 规则要求锁定一套 SVG 图标库、禁 emoji 图标；单人开发需要风格一致、tree-shakable、维护活跃的库。设计师已独立锁定 Lucide，架构师复核确认并实证 1.61.0 版本细节。

## Decision
lucide-react 为全项目唯一 UI 功能图标来源，**精确钉 1.61.0**（exact pin，非 caret——Lucide 的唯一消费方，升级需显式 ADR-lite 记录）。禁 react-icons 混装、禁 emoji 图标。尺寸规范：16px 行内 / 20px 按钮内 / 24px 独立图标；24px/2px outline 网格；tree-shake。

版本实证（2026-10-26，npm registry）：lucide-react 1.61.0 约 2,171 个条目；设计师 MVP 的 33 个功能图标中 31 个直接可用。

**已发生的破坏性变更（1.61.0 实证）**：
- **`github` 图标已从 Lucide 移除**（品牌图标清洗）——GUI 的 GitHub 入口槽位改用 Lucide `star` 图标 + 文字标签（如 "Star on GitHub"）；如坚持用 GitHub logo，按下方边界裁定作为品牌美术资产置于壳层资源目录。
- 重命名项旧别名（more-horizontal / alert-circle / alert-triangle / trash-2 / terminal）在 1.61.0 仍可导入，但项目统一使用新规范名。**已实证确认**：more-horizontal → ellipsis、alert-circle → circle-alert、alert-triangle → triangle-alert、terminal → square-terminal；trash-2 的新规范名由设计师在 Phase 2 图标映射表定稿时对照 Lucide 官方 rename 文档确认（旧别名仍可导入，无功能风险）。

## P0 规则边界裁定（2026-10-26）
- **UI 功能图标：100% Lucide，无例外**
- **应用图标（app icon）与托盘/菜单栏 template image：属品牌美术资产**（单色、macOS template image 规范、置于壳层资源目录），豁免图标库锁定，不构成「第二套图标库」
- **emoji 禁令全局有效**，不受边界裁定影响

## Consequences
- 正面：体积极小、风格统一、可访问性默认 aria-hidden；与设计师 Token 体系无缝集成。
- 负面：仅 outline 风格（设计已适配）；品牌图标需自行管理（github 入口已给替换方案）。
