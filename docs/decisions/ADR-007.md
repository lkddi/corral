# ADR-007: MVP 用 JSON 文件存储 + repository 抽象，SQLite 为演进位

## Status: Accepted (2026-10-26)

## Background
站点/设置/版本数据量为数十条级，并发低；better-sqlite3 需按 Electron ABI 重编，node:sqlite 仍带实验标记。

## Decision
JSON 原子写 + schema 版本号 + repository 接口抽象；数据量或并发成为瓶颈时切换 SQLite，业务层零改动。

## Consequences
- 正面：零原生依赖、零构建坑。
- 负面：无查询能力/无事务（当前不需要，接口已预留）。
